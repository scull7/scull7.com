## why
`elm.json` has empty `test-dependencies`; Format, Resume.mapResume, Fuzzy, and Highlight need fixture unit tests before CI can fail a PR on them.

## scope_in
- Add the `elm-test` package (authorized). No other new npm/elm packages.
- Unit tests for `Format`, `Resume.mapResume`, `Fuzzy`, and `Highlight` with **named expected values** (not tautologies) and the empty/no-match/invalid negatives below.
- Fixtures are **minimal JSON** (or equivalent Elm records). Production `public/resume.json` must not be the only case.
- npm script **`npm run test:elm`** runs elm-test (T-17 pins this argv). Wiring it into `npm test` is optional.

## scope_out
- routing / print / T-8 / new npm except elm-test (where relevant)
- Splitting `Main.elm` (T-14); Playwright (T-16); GitHub Actions (T-17)
- Tests whose only input is live `/resume.json` over HTTP
- Visual redesign; career-fact rewrites; hash routing; print CSS

## acceptance_criteria
- [ ] `elm.json` `test-dependencies` is **non-empty** and includes `elm-explorations/test` (or the equivalent this repo's elm-test runner expects). Empty `test-dependencies` **fails**.
- [ ] `package.json` has `"test:elm"` that runs elm-test. `npm run test:elm` with no tests installed **fails**.
- [ ] `npm run test:elm` exits 0 on the committed tests.
- [ ] **Format (named values, not non-empty):** `formatDate "2024-04"` equals `"April 2024"`. `formatDate ""` equals `""`. `formatDate "2024-13"` equals `"2024"` (invalid month). `formatDate "2024-xx"` equals `"2024"` (non-int month). `formatDateRange "2024-04" ""` equals `"April 2024 – Present"` (en-dash). A test that only asserts those strings are non-empty, or `Expect.equal True True`, **fails**.
- [ ] **Fuzzy (named values + negatives):** `score "abc" "abc"` equals `Just 0`. `score "a" "abc"` equals `Just 10`. `score "" "abc"` equals `Just 0` (empty query). `score "zzz" "abc"` equals `Nothing` (no-match). A test that only asserts `score "a" "abc" /= Nothing` **fails**.
- [ ] **Highlight (named values + empty):** `tokenize ""` equals `[]`. `tokenize "fn x"` contains a token `{ cls = "kw", text = "fn" }`. `tokenize "//c"` contains a token with `cls = "cm"`. `tokenize "\"ab\""` contains a token with `cls = "st"`. A test that only asserts `tokenize "x"` is non-empty **fails**.
- [ ] **mapResume (named fields + empty work):** a **minimal** fixture (JSON or Elm record, not a byte-copy of `public/resume.json` as the sole case) with `basics.name = "Ada Lovelace"` and one `work` job `name = "Analytical Engine"`, `position = "Programmer"` maps to `profile.name == "Ada Lovelace"`, `List.length experience == 1`, that job’s `company` containing `Analytical Engine` and `role == "Programmer"`. A second fixture with `work = []` maps to `experience == []` (does **not** invent jobs, does not crash). Using production `resume.json` as the **only** input, or only asserting `name` is non-empty, **fails**.
- [ ] The four modules above are all covered by those named assertions. Covering fewer than four **fails**.
- [ ] `node e2e/navigation.mjs` exits 0 (PASS).
- [ ] Identity lock (rewrite fails): `<title>Nathan Sculli</title>`; meta description, `og:description`, and `twitter:description` remain `Builder-leader · 20+ years · Rust · Distributed Systems`; `og:title` remains `Nathan Sculli — scull7.com`; Person JSON-LD still has `name` `Nathan Sculli`, `jobTitle` `Director of Engineering`, `worksFor` TensorWave with `https://tensorwave.com`, and `sameAs` `https://github.com/scull7` and `https://linkedin.com/in/scull7`.
- [ ] No new npm package besides `elm-test` (and its elm `test-dependencies`). Adding unrelated libraries **fails**.

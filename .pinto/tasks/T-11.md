## why
Crawlers that miss the SPA still need an explicit allow-list, a sitemap of the two public URLs, and a canonical that matches the existing `og:url`.

## scope_in
- Add `robots.txt` served at `/robots.txt` (Vite `public/` or equivalent so it lands in `dist/` after the production Vite build).
- Allow `/` and `/resume.json`. Do not Disallow CSS, JS, `/assets/`, `/styles/`, or other files the Elm shell needs.
- Include a Sitemap directive pointing at `https://scull7.com/sitemap.xml`.
- Add `sitemap.xml` listing at least `https://scull7.com/` and `https://scull7.com/resume.json`.
- Add `<link rel="canonical" href="https://scull7.com/">` in `index.html` (trailing slash, matching existing `og:url`).
- Keep existing title, meta description, OG/Twitter tags, and Person JSON-LD identity strings unchanged.

## scope_out
- Static HTML / noscript resume body (separate PBI).
- Headline / `basics.label` / OG / JSON-LD rewrite (“AI data center engineering leader” or any new tagline).
- Hash/path routing, full SSR, blog, case studies, print/PDF / `:print`.
- Restoring or redirecting `nathansculli.com` (T-8).
- New third-party dependencies.
- Changing Elm terminal visual design; splitting `Main.elm`; elm-test; GitHub Actions.
- Inventing MW/rack/GPU counts or unpublished TensorWave internals.

## acceptance_criteria
- [x] After `npm run build` (and after the Vite build step in `scripts/netlify-build.sh`), `dist/robots.txt` exists. Vite preview GET `/robots.txt` returns HTTP 200. The **response body** (not status alone) contains the robots tokens below. A body that is the app document — including `<div id="app">` — **fails** (SPA `index.html` served as `/robots.txt` is not a pass).
- [x] `dist/robots.txt` **and** the Vite preview GET `/robots.txt` body include a `User-agent: *` group (exactly `User-agent: *`, not a substitute user-agent) with `Allow: /` and `Allow: /resume.json`.
- [x] `robots.txt` does not `Disallow` `/`, `/resume.json`, `/styles/`, `/assets/`, `*.js`, or `*.css`.
- [x] `dist/robots.txt` **and** the Vite preview GET `/robots.txt` body contain the robots directive `Sitemap: https://scull7.com/sitemap.xml`.
- [x] After the same production build, `dist/sitemap.xml` exists. Vite preview GET `/sitemap.xml` returns HTTP 200. The **response body** is well-formed XML (not string-soup, not the app document): a `urlset` containing a `url` → `loc` for `https://scull7.com/` and a `url` → `loc` for `https://scull7.com/resume.json`. A body containing `<div id="app">` **fails**. Bare substring presence of those URLs without that `urlset` / `url` / `loc` structure **fails**.
- [x] Source `index.html` and `dist/index.html` contain **exactly one** `rel="canonical"` link, with `href="https://scull7.com/"` (trailing slash, matching `og:url`). `og:url` remains `https://scull7.com/`. Extra canonicals fail.
- [x] Identity lock (rewrite fails): `<title>Nathan Sculli</title>`; meta description, `og:description`, and `twitter:description` remain `Builder-leader · 20+ years · Rust · Distributed Systems`; `og:title` remains `Nathan Sculli — scull7.com`; Person JSON-LD still has `name` `Nathan Sculli`, `jobTitle` `Director of Engineering`, `worksFor` TensorWave with `https://tensorwave.com`, and `sameAs` `https://github.com/scull7` and `https://linkedin.com/in/scull7`.
- [x] GET `/resume.json` on Vite preview still returns HTTP 200. This PBI does not add a crawlable resume body; empty `#app` without the inject PBI is still allowed here.

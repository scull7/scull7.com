## why
After a T-16 named session, the recruiter human must verify the work email before any later booking. The agent requests mail, never reads inbox, and receives a short-lived book token only after the human click.

## scope_in
- POST `/interview/sessions/{id}/verify-request` and MCP `request_verification`.
- Isolated mail action (HTTP to the existing Resend sender). Fake sender in tests.
- Human GET `/interview/verify?token=` issues a session-scoped book token.
- Token HMAC + TTL as calculations. Default `INTERVIEW_MAGIC_LINK_TTL_MS` is 86400000 when unset.
- Named errors: `not_found`, `token_invalid`, `missing_env`.
- Turso persistence for tokens.

## scope_out
- T-18 required-set / `interview.completed`.
- T-19 `create_hold` / GCal / hold mail / `booking.requested`.
- GET-session.
- Returning the magic URL or book token on the agent-facing verify-request.
- Hand-authored JavaScript.
- New third-party mail SDK.

## acceptance_criteria
- [ ] After a T-16 session, POST `/interview/sessions/{id}/verify-request` is accepted and mail is sent only to that session work email. Agent JSON has no magic URL and no book token. MCP `request_verification` matches.
- [ ] verify-request on a never-created id → 4xx/404 error=not_found.
- [ ] Human GET `/interview/verify?token=` issues book_token, expires_at, session_id of the requesting session. Forged/empty/expired → error=token_invalid, no book token.
- [ ] Session A magic link never returns session_id B.
- [ ] Second GET of the same magic-link token → token_invalid, no book token.
- [ ] `INTERVIEW_MAGIC_LINK_TTL_MS=2000` then wait → GET verify token_invalid. Default unset remains 86400000. Tester clock, not a product reopen of short-lived.
- [ ] Q&A still works before and after verify. `create_hold` / MCP `create_hold` with no valid book token creates no calendar event.
- [ ] Missing `INTERVIEW_MAGIC_LINK_SECRET` or mail sender (`RESEND_API_KEY` / `INTERVIEW_RESEND_API_KEY`) → verify-request error=missing_env. No token issued.
- [ ] Contact nathan@vegasbuckeye.com. No street address. Agent never needs inbox access.

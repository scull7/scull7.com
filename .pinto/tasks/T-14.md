## why
`src/elm/Main.elm` is a 1176-line god-module; extract update, view, commands, keyboard, and palette into focused modules so later tests and error UX stay reviewable.

## scope_in
- Behavior-preserving extract of `src/elm/Main.elm` into focused modules (ROADMAP names: `Shell/Update.elm`, `Shell/View.elm`, `Shell/Commands.elm`, `Shell/Keyboard.elm`, `Shell/Palette.elm`; names may change if the seam is cleaner).
- Size bound: `Main.elm` and each **new** module created by this split stay under ~300 lines; no extract target is a new god-file.
- Keep the Elm/Vite/Melange production compile path working (`npm run elm:make` + `npm run build`).
- Visual and keyboard contract unchanged: palette, `j`/`k` buffer-row focus, Esc-from-terminal, `#terminal-input` autofocus on opening the terminal buffer, buffers — no new chrome.
- These three keyboard observers are **T-14 regressions** (browser/DOM). They do **not** require T-16’s committed e2e suite; T-16 must not be the only proof.
- Identity lock and T-13 crawlable noscript contract remain.

## scope_out
- routing / print / T-8 / new npm except elm-test (where relevant)
- Hash/path routing, `Browser.application`, print CSS / PDF / `:print`
- elm-test (T-15), Playwright expansion / `e2e/run.mjs` wiring (T-16), resume Http retry UX (T-18)
- Changing `resume.json` career facts; headline / OG / JSON-LD rewrite
- Visual redesign of live Elm buffers; vim-depth features
- Restoring `nathansculli.com` (T-8)

- [ ] Every **new** Elm module added by this split has `wc -l` **strictly less than 300**. A new module with ≥300 lines **fails**. A single dump of the old Main into one new file (line count ≥1176) **fails**.
- [ ] `npm run elm:make` exits 0.
- [ ] `npm run build` exits 0.
- [ ] `node e2e/navigation.mjs` exits 0 (PASS). Existing navigation.mjs **alone** does **not** prove the keyboard contract (it never presses `j`/`k` and never opens the terminal buffer).
- [ ] `npm run test:t13` exits 0.
- [ ] **j/k regression (DOM):** with `#palette.open` count 0, note which `#buffer-items .buffer-item` has `aria-selected="true"` and class `focused`. Press `j`. A **different** `#buffer-items .buffer-item` now has `aria-selected="true"` and class `focused`. Press `k`. The originally noted row is `aria-selected="true"` / `.focused` again. Reversed `j`/`k`, a no-op, or a move that does not change `aria-selected` **fails**. This AC is not satisfied by click-to-switch in `e2e/navigation.mjs`.
- [ ] **Esc-from-terminal regression (DOM):** open the terminal buffer (sidebar row whose `.name` is `terminal`). `#terminal-input` is `document.activeElement`. Press Escape. Esc that opens `#palette` or leaves `#terminal-input` focused **fails**. Existing navigation.mjs Esc-closes-palette does **not** satisfy this AC.

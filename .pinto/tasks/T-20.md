## why
`src/elm/Main.elm` is a 1176-line god-module; extract update, view, commands, keyboard, and palette into focused modules so later tests and error UX stay reviewable.

## scope_in
- Behavior-preserving extract of `src/elm/Main.elm` into focused modules (ROADMAP names: `Shell/Update.elm`, `Shell/View.elm`, `Shell/Commands.elm`, `Shell/Keyboard.elm`, `Shell/Palette.elm`; names may change if the seam is cleaner).
- Size bound: `Main.elm` and each **new** module created by this split stay under ~300 lines; no extract target is a new god-file.
- Keep the Elm/Vite/Melange production compile path working (`npm run elm:make` + `npm run build`).
- Visual and keyboard contract unchanged: palette, `j`/`k` buffer-row focus, Esc-from-terminal, `#terminal-input` autofocus on opening the terminal buffer, buffers — no new chrome.
- These three keyboard observers are **T-20 regressions** (browser/DOM). They do **not** require T-22’s committed e2e suite; T-22 must not be the only proof.
- Identity lock and T-13 crawlable noscript contract remain.

## scope_out
- routing / print / T-8 / new npm except elm-test (where relevant)
- Hash/path routing, `Browser.application`, print CSS / PDF / `:print`
- elm-test (T-21), Playwright expansion / `e2e/run.mjs` wiring (T-22), resume Http retry UX (T-24)
- Changing `resume.json` career facts; headline / OG / JSON-LD rewrite
- Visual redesign of live Elm buffers; vim-depth features
- Restoring `nathansculli.com` (T-8)

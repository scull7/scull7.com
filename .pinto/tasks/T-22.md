## acceptance_criteria
- [x] `npm run test:e2e` exits 0 **and** executes the new Esc / j-k-after-palette / terminal-autofocus cases. The suite moved off `e2e/*.mjs` to Melange before this card: the runner is `E2e_run`, which now spawns `e2e/keyboard` after `e2e/navigation`, so CI cannot miss it. A suite run only ad hoc **fails**.
- [x] The existing navigation suite still passes (`e2e/navigation PASS` inside `npm run test:e2e`). Deleting or skipping those cases **fails**.
- [x] **Esc cycle (DOM, more than today’s navigation.mjs):** today’s file already sends Escape to close `#palette` — that case **alone** does **not** pass this PBI. The suite must also: (1) open the terminal buffer (sidebar `.name` `terminal`); `document.activeElement.id` is `terminal-input`; press Escape; then `#palette.open` count is 0, `document.activeElement.id` is **not** `terminal-input`, and `#vim-root .statusline .mode` contains `NORMAL`; (2) after that Esc, press `:`; `#palette.open` count is 1 and `document.activeElement.id` is `palette-input`; press Escape; `#palette.open` count is 0. Esc that opens the palette from the terminal, or a suite that never opens the terminal buffer, **fails**.
- [x] **j/k after palette (DOM):** record the `.name` of `#buffer-items .buffer-item[aria-selected="true"]` (that row also has class `focused`). Press `:`; `#palette.open` count is 1. Press Escape; `#palette.open` count is 0. Press `j`. A **different** `#buffer-items .buffer-item` now has `aria-selected="true"` and class `focused`. Press `k`. The recorded row is `aria-selected="true"` again. Covering `j`/`k` only **before** the palette, or asserting movement without `aria-selected="true"` / `.focused` on `#buffer-items .buffer-item`, **fails**.
- [x] **Terminal autofocus (DOM, not page load):** open the terminal buffer (click the `terminal` row). `document.activeElement.id` is `terminal-input`. Asserting focus on GET `/`, `#app`, `#buffer-body`, or `#palette-input` after `:` does **not** satisfy. “Any focus assertion” **fails**.
- [x] No deep-link tests: the new e2e must not require `#/experience` or path routing. Adding those as required cases **fails** this PBI.

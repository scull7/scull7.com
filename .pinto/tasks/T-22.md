Playwright only covers a thin navigation path; ROADMAP 1.3 still needs Esc cycle, j/k after the palette, and terminal autofocus locked in e2e.

## scope_in
- Committed e2e assertions for: Esc cycle **beyond** existing “Esc closes `#palette`”, `j`/`k` **after** the command palette with named `aria-selected`, and `#terminal-input` focus **on opening the terminal buffer** (not page load).
- Keep existing `e2e/navigation.mjs` PASS (do not delete those cases).
- Extend Playwright/node e2e (same file and/or a new file). **`e2e/run.mjs` / `npm run test:e2e` must spawn the new cases** so T-23 cannot miss them. No new npm packages.
- Keyboard lives in the T-20 split; this PBI lands after that extract. T-20’s three regression observers stay true; this PBI is the dedicated suite, not the only proof of T-20.

## acceptance_criteria
- [ ] `npm run test:e2e` (`node e2e/run.mjs`) exits 0 **and** executes the new Esc / j-k-after-palette / terminal-autofocus cases (same file as navigation.mjs **or** an extra file that `e2e/run.mjs` actually spawns). A new e2e file run only ad hoc, not from `e2e/run.mjs`, **fails**.
- [ ] Existing `node e2e/navigation.mjs` still PASS (exit 0). Deleting or skipping those cases **fails**.
- [ ] **Esc cycle (DOM, more than today’s navigation.mjs):** today’s file already sends Escape to close `#palette` — that case **alone** does **not** pass this PBI. The suite must also: (1) open the terminal buffer (sidebar `.name` `terminal`); `document.activeElement.id` is `terminal-input`; press Escape; then `#palette.open` count is 0, `document.activeElement.id` is **not** `terminal-input`, and `#vim-root .statusline .mode` contains `NORMAL`; (2) after that Esc, press `:`; `#palette.open` count is 1 and `document.activeElement.id` is `palette-input`; press Escape; `#palette.open` count is 0. Esc that opens the palette from the terminal, or a suite that never opens the terminal buffer, **fails**.
- [ ] **j/k after palette (DOM):** record the `.name` of `#buffer-items .buffer-item[aria-selected="true"]` (that row also has class `focused`). Press `:`; `#palette.open` count is 1. Press Escape; `#palette.open` count is 0. Press `j`. A **different** `#buffer-items .buffer-item` now has `aria-selected="true"` and class `focused`. Press `k`. The recorded row is `aria-selected="true"` again. Covering `j`/`k` only **before** the palette, or asserting movement without `aria-selected="true"` / `.focused` on `#buffer-items .buffer-item`, **fails**.
- [ ] **Terminal autofocus (DOM, not page load):** open the terminal buffer (click the `terminal` row). `document.activeElement.id` is `terminal-input`. Asserting focus on GET `/`, `#app`, `#buffer-body`, or `#palette-input` after `:` does **not** satisfy. “Any focus assertion” **fails**.
- [ ] No deep-link tests: the new e2e must not require `#/experience` or path routing. Adding those as required cases **fails** this PBI.
- [ ] Identity lock (rewrite fails): `<title>Nathan Sculli</title>`; meta description, `og:description`, and `twitter:description` remain `Builder-leader · 20+ years · Rust · Distributed Systems`; `og:title` remains `Nathan Sculli — scull7.com`; Person JSON-LD still has `name` `Nathan Sculli`, `jobTitle` `Director of Engineering`, `worksFor` TensorWave with `https://tensorwave.com`, and `sameAs` `https://github.com/scull7` and `https://linkedin.com/in/scull7`.

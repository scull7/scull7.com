## why
Shared links should show a trustworthy person card and a PNG preview scrapers actually fetch, without turning the site into a marketing page.

## scope_in
- Add schema.org `Person` JSON-LD in `index.html` using only facts already in `resume.json` / this intent: name Nathan Sculli, url https://scull7.com, jobTitle Director of Engineering, worksFor TensorWave (https://tensorwave.com), sameAs GitHub + LinkedIn profile URLs, optional email already on the page.
- Confirm existing `og:*` and `twitter:*` text. **Decision (this PBI, not a later question):** ship `public/og.png` at 1200×630 as a sibling of `public/og.svg`; point `og:image` and `twitter:image` at absolute `https://scull7.com/og.png`. Keep the SVG. Visual remains the existing terminal/galaxy card (name + current `basics.label`). No new tagline.
- Fix the relative `/og.svg` share bug by using the absolute PNG URL.

## scope_out
- Last-updated statusline / help-strip chrome (separate PBI).
- Marketing landing page, light theme, PWA, analytics, i18n.
- Changing `basics.label` or inventing a new OG slogan.
- Valuation numbers in JSON-LD or OG description.
- Blog / writing surface. noscript SSR.
- New third-party social-preview services.

- [ ] `index.html` contains `<script type="application/ld+json">` whose parsed `@type` is `Person`, `name` is `Nathan Sculli`, `url` is `https://scull7.com`, `jobTitle` is `Director of Engineering`, `worksFor` names TensorWave **and** includes `https://tensorwave.com` (already `resume.json` `work[0].url`), and `sameAs` includes `https://github.com/scull7` and `https://linkedin.com/in/scull7`.
- [ ] JSON-LD does not include $350M, $1.55B, GPU counts, or unpublished metrics.
- [ ] `public/og.png` exists, is a PNG, and is 1200×630. `og:image` and `twitter:image` are `https://scull7.com/og.png` (absolute). `public/og.svg` remains.

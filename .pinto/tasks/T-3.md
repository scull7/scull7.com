## why
A recruiter or peer in the terminal can start email without hunting the home hero link or a calendar page.

## scope_in
- Command `:mail` (typed in the palette / cmdline) opens `mailto:nathan@vegasbuckeye.com?subject=scull7.com`.
- Palette command list includes `:mail` with a one-line description.
- `help.txt` lists `:mail` next to the other colon commands.
- To-address should match `basics.email` in `resume.json` (already `nathan@vegasbuckeye.com`); subject is the locked product string `scull7.com`.

## scope_out
- Calendar, booking, or scheduling links.
- Changing the home hero `mailto:` (may stay address-only).
- New contact form, analytics, third-party mail widget.
- Splitting `Main.elm`. New npm/opam dependencies unless a one-line existing port already opens URLs.

## acceptance_criteria
- [ ] Typing `:mail` and accepting the palette/command runs a navigation to `mailto:nathan@vegasbuckeye.com?subject=scull7.com` (to and subject exact).
- [ ] Command palette `:` mode lists a `:mail` row that performs the same action.
- [ ] `help.txt` visible command table includes `:mail` and states that it opens email (not a calendar).
- [ ] Unknown-command path is unchanged for typos (`:mai` still E492 or equivalent).
- [ ] No calendar URL, Calendly, or booking buffer is introduced.
